# UNIFORMEX · actualización de catálogo

Esta versión corrige las fotografías del catálogo y evita repetir imágenes entre productos.

## Archivos
- `index.html`
- `styles.css`
- `app.js`
- `banner-uniformex.webp`
- `assets/` (fotografías individuales y composiciones de paquetes)

## Publicar en GitHub
1. Descomprime este ZIP.
2. Entra al repositorio `stevengcmr-dev/Uniformex`.
3. Selecciona **Add file → Upload files**.
4. Arrastra los archivos de esta carpeta y la carpeta `assets` completa.
5. Confirma con **Commit changes**.
6. Netlify desplegará automáticamente los cambios al detectar el commit.

No cambies los nombres de los archivos ni la ubicación de `assets`.
