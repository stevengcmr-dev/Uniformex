# UNIFORMEX · actualización 3

Incluye:
- Playera Mujer SMN México Voluntaria con la fotografía proporcionada.
- Selector de talla CH, M, G, XL y XXL en playeras y sudadera.
- En paquetes, selección independiente de talla de playera y sudadera.
- Estado y municipio/alcaldía en el pedido de WhatsApp.
- Botón opcional para detectar ubicación aproximada mediante permiso del navegador y consulta a OpenStreetMap. Si no se concede permiso o falla la detección, se pueden escribir los datos manualmente.
- Conserva el carrito y el envío de pedidos por WhatsApp.

## Publicar
1. Descomprime este ZIP.
2. En GitHub abre el repositorio `stevengcmr-dev/Uniformex`.
3. Sube y reemplaza `index.html`, `styles.css`, `app.js` y la carpeta `assets` completa.
4. Pulsa **Commit changes**.
5. Netlify publicará el commit automáticamente.

No cambies los nombres ni la ubicación de los archivos. La ubicación es opcional; el botón de detección solicita permiso y consulta OpenStreetMap para convertir coordenadas en municipio y estado.
